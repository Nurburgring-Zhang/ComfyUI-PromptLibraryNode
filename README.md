# PromptLibraryNode Pro V20.5

一款为 ComfyUI 设计的全能提示词创作与故事板生成节点。支持 25 种创作模式，覆盖电影分镜、绘本、短剧、儿童动画、电商设计、品牌设计等场景。

## 核心功能

### 传统提示词库（Prompt Library）
读取本地提示词文件夹，支持 4 种读取模式（随机抽取/顺序循环/洗牌遍历/权重随机）、关键词/标签筛选、去重、AI 润色、AI 批量生成、多语言翻译。

### 故事板模式（9种）
- 电影分镜 — 专业的镜头语言输出（景别/场景/角色特征/画面/运镜/转场/时长/叙事功能）
- 广告故事板 — 卖点传达+品牌元素+产品机位
- 动画故事板 — 关键帧+表情动作+特效提示
- 漫画分镜 — 页面布局+对话框+拟声词
- MV故事板 — 歌词节奏同步+情绪曲线
- 教程步骤 — 步骤编号+操作说明+标注箭头
- 短视频分镜 — 竖屏9:16+前3秒钩子+情绪反转
- 品牌故事板 — 品牌色+LOGO+Slogan融合
- 剧情分镜 — 室内/室外场景+角色情绪+时空连续性

### 儿童内容模式（4种）
- 儿童视频格式一 — 多片段输出，含时空锚定/场景描述/动态描述/分镜场景/角色特征/旁白对话/特效TIPS
- 儿童视频格式二 — 四幕叙事结构（起承转合），含场景/画面描述/旁白/对话/动态描述/分镜场景/角色特征/TIPS
- 儿童微动视频/GIF — 逐页输出，核心动作+画面+动效循环，首帧等于末帧，适合循环动画
- 儿童绘本格式 — 逐页输出，画面+文案+旁白对话+视觉连续性提示+构图与景别

### 绘本模式
适合亲子朗读的绘本故事创作，含年龄段适配、文字量控制、构图与景别提示。

### 短剧模式
竖屏9:16短剧分镜，含节奏控制、情绪反转、留钩子。

### 专业设计模式（8种）
- 电商套图 — 产品主图/模特展示/场景图/细节图/白底图/功能卖点图
- 海报设计 — 音乐海报/电影海报/活动海报/LOGO海报/艺术海报
- 品牌设计 — 品牌LOGO/名片/包装/吉祥物/VI手册
- PPT设计 — 封面/目录/过渡/内容/图表/结尾
- 逻辑关系图 — 流程图/架构图/时间线/对比图/数据可视化
- 三视图设计 — 产品三视图/建筑立面/角色转面/机械结构
- 爆炸拆解图设计 — 产品拆解/建筑剖面/机械结构分解/电路示意图
- 流水线图设计 — 生产流程/数据管道/工作流/供应链/烹饪步骤

### 核心特性
- 故事感总纲 — 内置 25 种世界级故事模式随机抽取，为每个故事提供结构设计核心
- 参考图导入 — 最多 9 张参考图，自动保持角色和风格一致性（需前端UI支持）
- AI 集成 — 兼容任何 OpenAI 兼容 API（本地 LM Studio/Ollama/远程 API）
- 纯文字输出 — 所有模式输出纯净中文，无符号标记，可直接用于 AI 绘画/视频生成工具
- 输出约束 — 输出内容不含 #、**、编号前缀、分隔线等装饰符号
- 六大输出端口 — 分别对应传统提示词/绘本/短剧/故事板/负面词/儿童内容

## 安装

### 方法一：ComfyUI Manager（推荐）

在 ComfyUI Manager 中搜索 `PromptLibraryNode` 安装。

### 方法二：手动安装

```bash
cd ComfyUI/custom_nodes/
git clone https://github.com/Nurburgring-Zhang/ComfyUI-PromptLibraryNode.git
```

重启 ComfyUI 后即可使用。

## 使用方法

1. 在 ComfyUI 中添加 `PromptLibraryNodePro` 节点
2. 在参数面板中选择模式（共 25 种）
3. 根据模式填写主题、角色描述、环境背景等参数
4. 连接到任意文本显示/保存节点查看输出

### AI 功能配置

节点支持本地或远程 AI 调用（用于润色/生成/模式输出），在节点参数中配置：

| 参数 | 说明 | 示例 |
|------|------|------|
| API地址 | OpenAI 兼容 API 地址 | `http://localhost:1234/v1/chat/completions` |
| API密钥 | API 密钥 | 留空或填写 |
| AI模型名 | 模型名称 | `gpt-4` / `deepseek-chat` |
| AI推理温度 | 0.0-2.0 | `0.8` |
| AI最大Token数 | 输出长度限制 | `10000` |

不配置 AI 时，节点使用内置模板和规则引擎生成内容。

## 节点参数说明

### 基础参数
| 参数 | 类型 | 说明 |
|------|------|------|
| 文件夹路径 | String | 提示词库文件夹路径 |
| 读取模式 | 枚举 | 随机抽取/顺序循环/洗牌遍历/权重随机 |
| 循环模式 | 枚举 | 无限循环/读完停止/历史不重复 |
| 输出数量 | INT | 1-50 |
| 关键词筛选 | String | 按关键词过滤提示词 |
| 标签筛选 | String | 按标签过滤提示词 |

### 创作参数
| 参数 | 类型 | 说明 |
|------|------|------|
| 模式选择 | 枚举 | 25种创作模式 |
| 故事剧本 | String | 故事摘要或分镜剧情 |
| 角色描述 | String | 角色外貌、性格、服装 |
| 环境背景描述 | String | 场景地点、时间、氛围 |
| 总页数/总片段数 | INT | 1-60 |
| 画面风格 | 枚举 | 20+风格选项 |
| 色彩基调 | 枚举 | 暖色调/冷色调/高对比/低饱和 |
| 首选景别 | 枚举 | 全景/中景/近景/特写/混合 |
| 运镜风格 | 枚举 | 固定/手持/推拉/跟拍/升降/斯坦尼康/混合 |

### AI 参数
| 参数 | 类型 | 说明 |
|------|------|------|
| API地址 | String | OpenAI 兼容 API 地址 |
| API密钥 | String | API 密钥 |
| AI模型名 | String | 模型名称 |
| AI推理温度 | Float | 0.0-2.0 |
| AI最大Token数 | INT | 256-100000 |

## 依赖

- ComfyUI（任意版本）
- 无第三方 Python 包依赖（仅使用标准库）

## 输出规范

所有模式输出均遵循以下约束：
- 纯中文叙述，无 `#`、`**`、`- 开头` 等符号标记
- 无编号前缀（1、2、3、）
- 无分隔线（---）
- 维度之间用换行自然分隔
