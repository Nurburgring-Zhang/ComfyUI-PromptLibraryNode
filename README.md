# PromptLibraryNode Pro

一个 ComfyUI 节点，帮你写提示词和生成故事板。

## 它能干什么

**读提示词库**
设置一个文件夹路径，节点会从里面的文本文件里读取提示词。支持随机抽、顺序读、洗牌、按权重抽四种模式。可以按关键词或标签筛选，历史不重复，还能 AI 润色、批量生成、翻译。

**生成故事板（9种模式）**
- 电影分镜 — 景别、运镜、转场、时长，按镜头一个一个出
- 广告故事板 — 卖点、品牌元素、产品怎么摆
- 动画故事板 — 关键帧、表情动作、特效
- 漫画分镜 — 页面布局、对话框、拟声词
- MV故事板 — 跟歌词节奏走
- 教程步骤 — 一步一步教
- 短视频分镜 — 竖屏，前3秒抓人
- 品牌故事板 — LOGO、品牌色融进画面
- 剧情分镜 — 室内室外切换

**生成儿童内容（4种模式）**
- 儿童视频格式一 — 动画分镜，有时间地点、场景描述、对话
- 儿童视频格式二 — 起承转合四幕结构，有场景标签、旁白、角色对话、TIPS
- 儿童微动视频/GIF — 逐页出，每页写核心动作、画面、动效循环方式
- 儿童绘本格式 — 逐页出，画面描述、文案、旁白对话、构图景别

**绘本模式**
给亲子朗读用的故事，可以控制文字量和年龄段。

**短剧模式**
竖屏短剧分镜，控制节奏和反转。

**专业设计（8种模式）**
- 电商套图
- 海报设计
- 品牌设计
- PPT设计
- 逻辑关系图
- 三视图
- 爆炸拆解图
- 流水线图

## 怎么装

**方法一：Manager 搜**
在 ComfyUI Manager 里搜 PromptLibraryNode 安装。

**方法二：手动拉**
```bash
cd ComfyUI/custom_nodes/
git clone https://github.com/Nurburgring-Zhang/ComfyUI-PromptLibraryNode.git
```

装完重启 ComfyUI。

## 怎么用

1. 添加 PromptLibraryNodePro 节点
2. 选一个模式（一共25种）
3. 填主题、角色描述、环境背景
4. 接一个文本显示节点看输出

**AI功能不是必须的。** 你可以在节点参数里配API地址和密钥来用AI生成，不配的话节点用内置模板和规则引擎出内容。

## 输出说明

所有模式输出都是纯中文，没有 ##、**、---、编号前缀这些符号。维度之间换行分隔，直接拿去用。
