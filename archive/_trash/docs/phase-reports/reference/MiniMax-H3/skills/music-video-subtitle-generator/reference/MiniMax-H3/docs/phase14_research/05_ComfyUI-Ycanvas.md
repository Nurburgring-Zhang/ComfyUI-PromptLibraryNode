## 项目简介

Comfyui-Ycanvas 是一个为 ComfyUI 增添"无限画布"般交互体验的插件。它提供一个独立的 Web 画布弹窗,支持拖拽缩放、旋转前景图,让用户可以在 ComfyUI 界面中进行图像编辑和操作。

---

## 核心功能

- **独立的 Web 画布弹窗**
- **拖拽缩放**
- **旋转前景图**
- **快捷键** (R/←→/±)
- **透明度调节**
- 直观的操作方式

## 同类"无限画布"交互插件对比

| **was-node-suite-comfyui** | 综合性节点套件,大量图像处理、文本操作和工作流管理工具 | 一站式解决方案 |
| **ComfyUI-VideoBlender** | 视频混合与合成,类似图层的视频混合节点,多种混合模式、位置变换和GPU加速 | 多轨道视频合成 |
| **ThoughtBubble** | 可视化、可拖拽的"思想泡泡"画布,构建和管理提示词,支持动态命令、条件逻辑、变量控制 | 复杂动态提示词逻辑 |
| **SeedEdit v1.5 (x2i_comfyui)** | 火山引擎指令式图像编辑,通过自然语言指令修改图像主体、妆造、背景、画风 | 智能文字指令修图 |

## 选型建议

### 追求最接近 Ycanvas 的直观手动画布体验
优先尝试 **ComfyUI Web Canvas Node**,它的拖拽、缩放、旋转操作逻辑和 Ycanvas 非常相似。

### 像 Photoshop 那样精细控制
**LayerStyle Advance 套件** 是必备之选。从混合模式到颜色调整的"原子级"节点。

### 视觉化提示词管理
**ThoughtBubble** 提供了一个全新的视觉化思路。

### AI 指令修图
**SeedEdit** 这类 AI 指令编辑插件,代表了一种不同的交互哲学。

## 类似的独立 infinite-canvas 项目

infinite-canvas (无限画布) 这个项目,核心是提供了一个本地或可部署的"一站式工作台":

### 核心能力
1. **提示词管理** - 保存、分类、复用、组合常用提示词或模板
2. **素材库集成** - 上传参考图(风格、构图、元素),在生成时方便引用
3. **批量任务队列** - 配置好一组参数(模型、采样器、步数等)和一系列提示词,一键提交批量生成任务
4. **画布/工作区概念** - 提供可视化的空间来组织灵感、草图和最终成品

### 适合谁用
- 高频内容创作者:定期生产系列配图,风格一致
- 产品/UI 概念设计师:快速生成同一主题的不同设计方案
- 独立游戏开发者/同人创作者:为角色、场景、道具生成大量变体
- 提示词工程学习者:系统管理提示词实验,对比不同参数

### 不适合
- "偶尔生成一张好看的壁纸"的轻度用户

## 部署关键点

- **环境**: Linux 首选,Windows 路径/权限问题多,macOS Apple Silicon 体验较好
- **Python**: 3.8-3.10,使用独立虚拟环境
- **后端**: 通常通过 API 与 WebUI/ComfyUI 通信,需先确保后端能独立运行
- **硬件**: NVIDIA 6GB+ 显存 (基础), 16GB 系统内存
- **磁盘**: SSD, 批量出图时写入是瓶颈

## 关键技术点

### 变量替换 (通配符)
```python
# 模板
template = "a photo of {animal}, in the style of {style}"

# 变量列表
animals = ["cat", "dog", "rabbit"]
styles = ["cyberpunk", "watercolor", "oil painting"]

# 排列组合 3x3=9 种结果
```

### 任务参数配置
- 模型、采样器、步数、分辨率统一
- 输出命名规则: `{animal}_{style}_{index}.png`
- 并发数 = 显存约束下的最大值

## 与我们项目的关系

**类别: 互补 (用户交互层) + 高借鉴 (批量/变量替换)**

### ⭐⭐⭐⭐⭐ 批量任务队列 (核心借鉴!)

**借鉴方向:**
- 我们当前每个节点单独工作,无批量任务管理
- 应学习 infinite-canvas 的 **变量替换 + 排列组合** 模式:
  - 用户定义"角色" `["林黛玉", "薛宝钗", "王熙凤"]` + "场景" `["大观园", "潇湘馆", "怡红院"]`
  - 我们的 director_storyboard_pro 自动生成 3x3=9 个分镜
- 当前我们的 `script_body_pro.py` 是单次输出,这是关键改进点!

### ⭐⭐⭐⭐ 素材库/标签管理 (高借鉴!)

**借鉴方向:**
- 我们当前的 `director_pro.py` 63位导演库是硬编码 Python dict
- 应学习 infinite-canvas 的**素材库集成**:
  - 用户上传参考图(导演风格代表作)
  - 在生成时方便引用
  - 我们的 22种类型片视觉语言也可关联参考图

### ⭐⭐⭐⭐ 画布/工作区概念 (中借鉴)

**借鉴方向:**
- 我们当前是单次"生成-输出"模式
- 应学习画布/工作区:
  - 一次生成 25 个分镜 → 画布上显示
  - 拖拽调整顺序、删除不满意、重新生成单个
  - 这就是 `comfyui-storyboard` 项目的核心

### ⭐⭐⭐ 变量替换+权重 (中借鉴)

**借鉴方向:**
- 我们的通配符/变量化程度不够
- `director_pro.py` 中"徐克" 0.6 + "黑泽明" 0.4 = "混搭导演风格" 应支持

### 互补关系
- 无限画布 = **用户界面层** (可视化、批量)
- 我们 = **导演领域知识** (故事/分镜/导演)
- 完美组合: 用户在画布上拖拽分镜 → 我们的 director_storyboard_pro 重新生成

### 直接给我们的改进方向
1. **新节点 `batch_storyboard_pro.py`** - 真正的"批量变量+排列组合" 模式
2. **director_pro.py** - 标签可视化+拖拽管理界面
3. **新节点 `storyboard_canvas_pro.py`** - 网格视图分镜,拖拽调整,类似 StoryDiffusion 的画布
4. **pln_random.py** - 增加变量替换功能
